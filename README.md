# Initial-document-approval-system
Бичиг баримтыг цахимаар илгээх, хянах, засварлах, баталгаажуулах, хувилбарын түүх болон хэрэглэгчийн үйлдлийг бүртгэх байгууллагын дотоод удирдлагын систем. Next.js, TypeScript, MongoDB технологид суурилсан.
# 📄 Бичиг баримтын хяналт, баталгаажуулалтын систем

Байгууллагын дотоод бичиг баримтыг цахим хэлбэрээр илгээх, хянах, засварлах, баталгаажуулах болон үйл ажиллагааны түүхийг бүртгэх зориулалттай веб систем.

## 🎯 Системийн зорилго

Байгууллагын ажилтнуудын боловсруулсан Word болон бусад бичиг баримтыг удирдах албан тушаалтнуудад цахимаар хүргүүлэх, хянуулах, засварлуулах, баталгаажуулах үйл ажиллагааг нэг системээр зохион байгуулахад оршино.

Ингэснээр бичиг баримтыг цаасаар дамжуулах үйл ажиллагааг багасгаж, баримт бичиг хаана, ямар шатанд байгааг хянах боломж бүрдэнэ.

## ⚙️ Үндсэн боломжууд

### 👤 Хэрэглэгчийн удирдлага

- Ажилтан шинээр бүртгэх
- Хэрэглэгчийн мэдээлэл засах
- Албан тушаал болон хэлтэс/алба бүртгэх
- Нууц үг солих
- Хэрэглэгчийг идэвхжүүлэх болон идэвхгүй болгох
- Системийн эрхийн түвшин тохируулах

### 🔐 Эрхийн удирдлага

Систем нь хэрэглэгчийн үүргээс хамаарсан эрхийн зохицуулалттай.

- EMPLOYEE — Ажилтан
- REVIEWER — Хянагч
- DIRECTOR — Захирал
- ADMIN — Системийн администратор

Хэрэглэгч бүр зөвхөн өөрт олгогдсон эрхийн хүрээнд системийн функцүүдэд хандана.

## 📤 Бичиг баримт илгээх

Ажилтан системд нэвтэрч өөрийн боловсруулсан бичиг баримтыг оруулан хянуулах албан тушаалтныг сонгож илгээх боломжтой.

Баримт бичгийн мэдээлэлд:

- Баримтын нэр
- Файлын нэр
- Илгээсэн ажилтан
- Хэлтэс / алба
- Хянуулах ажилтан
- Илгээсэн огноо, цаг
- Баримтын төлөв

зэрэг мэдээлэл хадгалагдана.

## 🔎 Бичиг баримт хянах

Хянагч өөрт ирсэн бичиг баримтыг:

- Харах
- Татаж авах
- Хянах
- Санал, тайлбар бичих
- Засварласан хувилбар оруулах
- Засварт буцаах
- Хянасан төлөвт оруулах
- Дараагийн шатанд шилжүүлэх

боломжтой.

## 📚 Version History

Бичиг баримтад хийсэн өөрчлөлт бүрийг шинэ хувилбар болгон хадгална.

Жишээ:

- Version 1 — Ажилтны анх оруулсан файл
- Version 2 — Хянагчийн засварласан файл
- Version 3 — Дахин засварласан файл
- Final Version — Баталгаажсан хувилбар

Ингэснээр өмнөх файлууд устахгүй бөгөөд бичиг баримтын өөрчлөлтийн түүхийг шалгах боломжтой.
